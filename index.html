Protótipos de tela

HTML descartável, feito para discutir conceito, cor, tipografia e animação antes de existir código React. Nenhuma tela é implementada sem protótipo aprovado.

Comece pelo 00 — Sistema de design. Os seletores da barra preta (cor, modo, fonte, motion) valem para todas as telas e ficam salvos no navegador — troque ali e navegue para comparar o conjunto.

Como aprovar

  1. Abra o protótipo e leia o bloco "Decisões a aprovar" no fim da página.
  2. Diga "aprovado" (ou o que mudar). O arquivo é movido para prototypes/approved/.
  3. Só então a tela vira ticket de implementação em React.
  4. Ideia recusada vai para prototypes/discarded/ — fica como registro do que já se tentou.
